# 調整さんをもっと便利に！

- [GitHub Pagesで公開中](https://akashisekizaki.github.io/chouseisan_more_convenient/)
- [利用動画](https://drive.google.com/file/d/13Qb5QDMk2H7Pi0qa5xf_CVM8mG516M52/view?usp=sharing)

## 当時のレベル
- 学部3年次
- HTML，CSS，JavaScriptでチーム開発を1年行う

## 開発背景
- 「調整さん」の日程候補を入れるのがスーパー面倒である！
  - 参加している[メタ学習ラボ（学習支援組織）](https://www.fun.ac.jp/meta-leaning)ではMTGは調整さんで行なっているが，1週間分の1~5限までの調整を行う
    - 項目を7日*5限分 = 35項目作る必要があった
    - 月に数回これが飛び交う...
  - 他活動での飲み会や日程調整でも...

## 使い方
1. 日程を入力（後の日程の方が早いとエラー）
1. 時間を選択
1. 選択したい時間がなければ追加
1. 日付リストを生成をクリック
1. コピーボタンをクリック
1. 調整さんを開いて，日程候補にペースト

## 苦戦したところ
#### クリップボードでのコピー機能
当時はGCPでサーバーを立てて動かす想定だった.ローカル環境で動くことを確認し，サーバーに上げるとクリップボードへのコピーができなかった．原因を調査したところ，使用していた`navigator.clipboard`はSSL認証のないサーバーでは動作しないことが分かった．
